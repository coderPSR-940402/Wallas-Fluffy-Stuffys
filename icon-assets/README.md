# Walla's Fluffy Stuffy's icon assets

The v1.0.0 asset package is assembled by GitHub Actions from the four archive parts uploaded at the repository root:

- Wallas-assets.part01
- Wallas-assets.part02
- Wallas-assets.part03
- Wallas-assets.part04

The parts are reassembled and SHA-256 verified before the WebP artwork and icon-pack XML are copied into Android resources.
